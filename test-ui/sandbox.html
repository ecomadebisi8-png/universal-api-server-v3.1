Project sandboxes

Alpha and Beta are identical protected playgrounds — JWT or API key required. The response echoes which identity you used.

🅰️ Project Alpha
Protected sandbox — authOrApiKey middleware on every route.
GET/api/v1/project-alpha identity check
GET/api/v1/project-alpha/items
POST/api/v1/project-alpha/items
🅱️ Project Beta
Same rules, different sandbox — handy for testing key scoping across projects.
GET/api/v1/project-beta identity check
GET/api/v1/project-beta/items
POST/api/v1/project-beta/items
🔍 How identity is resolved
The endpoint answers show whether you arrived as a user (JWT) or a service (API key):
{
  "project": "alpha",
  "authenticated": true,
  "user":    { "id": "…", "email": "you@example.com" },   // JWT path
  "service": { "name": "…", "permissions": ["read","write"] } // API-key path
}
