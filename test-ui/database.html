D1 items

The generic resource table behind /api/v1/db/items. Since v3.1 reads and writes require a session — no more anonymous D1 writes.

✨ Create item
POST /api/v1/db/items — non-empty, ≤ 200 chars.
🔎 Read items
GET /api/v1/db/items — newest first · GET /api/v1/db/items/:id — one item.
🗑️ Delete item
DELETE /api/v1/db/items/:id — deleting a missing id returns a real 404.
Tip: list items, then paste an ID here — delete it, then delete again to see the 404.
🧰 Table bootstrap
POST /api/v1/db/_init — idempotent. Also runs automatically once per isolate on cold start.
