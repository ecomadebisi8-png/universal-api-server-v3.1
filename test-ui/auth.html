Auth module

Register, login, token rotation, logout, password change and OTP. Successful logins capture tokens into the session bar automatically.

✨ Register
POST /api/v1/auth/register — min 8 chars, valid email. Returns a full token pair.
🔑 Login
POST /api/v1/auth/login — issues a fresh token pair and a rotated refresh token.
👤 Who am I
GET /api/v1/auth/me — verifies the session token and echoes the payload.
// check token to see your identity card
🔄 Refresh & rotate
POST /api/v1/auth/refresh — old refresh tokens die on use (single-use rotation).
🚪 Logout
POST /api/v1/auth/logout — kills one refresh token · /logout-all — kills every session for the user.
🛡️ Change password
POST /api/v1/auth/change-password — revokes all refresh tokens. Same as old → 400. Min 8 chars.
✉️ OTP codes
POST /api/v1/auth/send-otp · /verify-otp. Production never echoes the code — 10 min expiry, dead after 5 failed attempts.
